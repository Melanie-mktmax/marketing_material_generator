# Marketing Material Generator (KO → EN)

메디컬 에스테틱 PM용 마케팅 자료 생성기. 원천 정보(신규 임상 데이터 / 경쟁사 동향)를 넣으면
**국문(국내용) 자료를 먼저** 만들고, 검수·편집 후 **영문(해외용) 세트로 변환**합니다.

- 게시 주소: https://claude.ai/code/artifact/3ead1455-583e-4832-bba7-baf2070e2902
- 소스: `index.html` 한 파일 (React 18 + Tailwind CSS, 빌드 없이 동작)

## 산출물 (탭 4개, 국문/영문 각각)

| # | 국문 (국내용) | English (해외용) |
|---|---|---|
| 1 | 핵심 메시지 | English Key Messages |
| 2 | B2B 세일즈 디테일 시트 | B2B Sales Detail Sheet Copy |
| 3 | B2C 인스타그램 캡션 | B2C Instagram Caption |
| 4 | 디스트리뷰터 피치 이메일 (국내 총판·대리점) | Distributor Pitch Email (해외 디스트리뷰터) |

## 사용 흐름

1. 좌측에서 **브랜드**(DCLASSY / Facetem / 리알로)와 **타겟 채널**(B2B Academic / B2B Sales / B2C SNS)을 고릅니다.
   - "브랜드 보이스 편집"에서 영문 브랜드명과 톤 메모를 수정할 수 있습니다(브라우저에 저장). 초기값은 예시입니다.
2. 중앙에 **원천 정보**를 넣습니다. 유형 토글로 임상 데이터 / 경쟁사 동향을 지정합니다.
   - **직접 입력**: 텍스트로 붙여 넣기(한국어·영어 모두 가능).
   - **원천 파일 올리기**: 임상 보고서·통계 표·경쟁사 리포트 원본을 그대로 업로드. 입력창과 **동등한 1차 자료**로 읽어 수치를 파일에서 인용합니다. 입력창을 비워 두고 파일만 올려도 됩니다. 각 파일의 `입력창으로` 버튼을 누르면 추출된 텍스트를 입력창으로 옮겨 직접 수정할 수 있습니다.
   - **참고 자료**(그 아래): 브랜드 가이드·기존 카피·용어집처럼 **톤과 용어를 맞출** 자료. 사실의 출처가 아니라 표현 참고용입니다.
   - 지원 형식: PDF · DOCX · PPTX · XLSX · TXT · MD · CSV · JSON. claude.ai에서 이미지 첨부가 가능한 화면이면 JPEG/PNG/WebP/GIF도 올릴 수 있습니다(국문 생성 시 비전으로 전달, 원천 이미지가 우선 전달됨).
3. **국문 생성** → 4개 탭에 국문 초안이 스트리밍됩니다.
4. 탭별로 검수하고, 필요하면 **편집**(마크다운 그대로 수정) → 저장.
5. **영문 변환** → 검수된 국문을 기준으로 해외용 영문 세트를 만듭니다. 상단 토글로 국문/English를 오갑니다.
   - 영문 변환 후 국문을 다시 편집하면 영문에 "다시 변환 필요" 표시가 뜹니다.
6. 탭별 **복사** 또는 **전체 복사**로 가져갑니다.

## 프롬프트에 내장된 규칙

- 원천 정보·참고 자료에 있는 사실만 사용. 수치·적응증·인허가·기전·가격을 지어내지 않고, 부족하면 `[PM: …]` 플레이스홀더로 표시(화면에 노란 칩으로 강조).
- 수치는 항상 연구 맥락(대상 수·기간·평가지표)과 함께. 절대적·최상급 표현 금지.
- **국문**: 국내 의료광고·의료기기 광고 규정을 고려한 표현, B2C에는 `[광고심의 확인 필요]` 플레이스홀더.
- **영문**: 직역이 아닌 트랜스크리에이션. 사실·수치 동일 유지, 해외 시장용 클레임 규칙 적용, "Individual results vary. Availability and indications vary by market." 포함.
- 경쟁사 동향 입력 시: 비방 없이 '확인된 강점' 기반 차별화 포지셔닝.

## 기술 메모

- 생성은 Claude 아티팩트의 `sample` 런타임 기능(`claude.use("sample")`)으로 수행됩니다.
  → **claude.ai에서 아티팩트로 열어야 생성이 동작**합니다. 파일을 로컬에서 열면 UI는 보이지만 생성 버튼은 비활성입니다.
- 첫 생성 시 "This artifact uses connectors — Use Claude" 동의 창이 뜹니다. 사용량은 보는 사람 본인 계정에 과금됩니다.
- 입력값, 생성 결과, 참고 자료에서 추출한 텍스트는 보는 사람의 브라우저 `localStorage`에만 저장됩니다(서버 저장 없음). 이미지는 세션 동안만 유지됩니다.
- 참고 자료는 브라우저 안에서 텍스트로 추출합니다 — DOCX/PPTX/XLSX는 JSZip으로 XML을 풀고, PDF는 pdf.js(텍스트 레이어 필요, 스캔본은 이미지로 첨부)로 읽습니다.
- 프롬프트 한도는 65,536바이트(UTF-8)입니다. 배분 순서는 ① 직접 입력한 원천 정보 ② 원천 파일 ③ 참고 자료이며, 원천 정보(입력+파일) 합계는 36 KB까지입니다. 여유가 부족하면 파일 목록에 "일부" 또는 "제외" 표시가 뜹니다.
- 출력은 `## [1] KEY MESSAGES` … `## [4] DISTRIBUTOR PITCH EMAIL` 헤더로 구분되며, 앱이 이를 파싱해 탭으로 나눕니다.
- CDN: React / ReactDOM / Babel standalone / JSZip / pdf.js(cdnjs), Tailwind Play CDN, Google Fonts(Newsreader · Noto Serif KR · Archivo · IBM Plex Mono).

## 수정 후 재게시

`index.html`을 고친 뒤 Claude Code에서 같은 아티팩트 URL로 다시 게시하면 주소가 유지됩니다.

## 공유 (Access)

아티팩트 화면 우상단 **Share** → General access에서 권한을 정합니다. 이 앱은 Claude를 호출하므로
"Anyone with the link"(전체 공개)는 선택할 수 없고, **"Only people with access"**만 가능합니다.
즉 링크를 받은 사람이 접근을 요청하면 소유자(Melanie)가 승인해 주는 방식으로 동작하며,
승인된 사람은 각자 자기 Claude 계정 사용량으로 생성 기능을 쓸 수 있습니다.
